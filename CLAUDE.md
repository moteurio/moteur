# Moteur

Follow the "Writing: commits, comments, tests" section of CONTRIBUTING.md for every commit message, code comment, test name and doc you write. In short:

- Commits: Conventional Commits, imperative and concrete (`fix(x): reject empty slugs`). No ticket codes or private names.
- Comments: full plain sentences that explain why. No colon-separated fragments, no history ("used to", "no longer"), no Moteur Studio internals.
- Test names state the behaviour under test.
